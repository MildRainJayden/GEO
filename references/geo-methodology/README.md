# GEO / AI 可见度测评方法论参考资料

本目录收录用于支撑 AIVC 测评流程、指标设计、证据链与风险说明的公开论文和官方框架。使用时建议分清证据等级：正式发表论文和政府/标准机构文件可作为核心依据；arXiv 预印本可作为行业趋势和方法参考，不宜单独作为“权威定论”。

## 核心依据

1. `01_GEO_Generative_Engine_Optimization_KDD2024_Aggarwal.pdf`
   - 证据等级：正式会议论文。
   - 支撑点：GEO 概念、生成式搜索中的内容可见度、引用/推荐/印象等生成引擎优化目标。
   - 对应本项目：GEO 优化建议、引用来源、AI 可见度诊断。

2. `02_HELM_Holistic_Evaluation_Language_Models_TMLR2023_Liang.pdf`
   - 证据等级：正式期刊/评测框架论文。
   - 支撑点：多场景、多指标、多模型的语言模型评测思想，强调透明、可复现、分维度评估。
   - 对应本项目：多模型测评、问题集分层、平台表现分模型展示。

3. `03_NIST_AI_RMF_1_0_2023.pdf`
   - 证据等级：NIST 官方框架。
   - 支撑点：AI 风险管理、可信、可解释、可追溯、治理流程。
   - 对应本项目：可信度说明、证据包、客户质疑时的风险边界说明。

4. `04_NIST_Generative_AI_Profile_AI600_1_2024.pdf`
   - 证据等级：NIST 官方生成式 AI 风险画像。
   - 支撑点：生成式 AI 的幻觉、错误信息、引用不可靠、内容溯源等风险。
   - 对应本项目：不把模型回答当作事实数据库，保留原始回答和来源证据。

5. `05_EACL2026_Web_Search_Credibility_Groundedness.pdf`
   - 证据等级：正式会议论文。
   - 支撑点：搜索增强聊天助手的来源可信度、回答 groundedness、引用质量评估。
   - 对应本项目：引用来源模块、引文类别、页面类型、来源可信度说明。

## 行业前沿参考

6. `06_Synthetic_Sources_Generative_Search_Citations_arXiv2026.pdf`
   - 证据等级：arXiv 预印本。
   - 支撑点：生成式搜索引用可能出现合成来源、虚假或不可验证来源，需要审计。
   - 对应本项目：AI 幻觉风险提示、引用来源可追溯。

7. `07_What_Gets_Cited_Competitive_GEO_SIGIR2026_preprint.pdf`
   - 证据等级：arXiv 预印本。
   - 支撑点：AI answer engines 中哪些页面/品牌更容易被引用，竞争性 GEO 指标。
   - 对应本项目：竞品声量、引用域名、被引用 URL 排名。

8. `08_GEO_at_Scale_Brand_Visibility_AI_Search_Engines_arXiv2026.pdf`
   - 证据等级：arXiv 预印本。
   - 支撑点：跨 AI 搜索引擎衡量品牌可见度、问题集、行业和模型差异。
   - 对应本项目：品牌 AI 声量、平台得分、跨模型综合。

9. `09_Critical_Survey_GEO_2023_2026_arXiv2026.pdf`
   - 证据等级：arXiv 预印本。
   - 支撑点：GEO 领域综述、方法边界和研究脉络。
   - 对应本项目：对外说明“AI 可见度测评”仍是新兴领域，需以诊断工具定位。

## 对客户的推荐表述

本测评不是传统市场份额或销售数据报告，而是基于公开论文中的 GEO 思路、语言模型评测框架和 AI 风险治理原则，衡量品牌在大模型回答中的可见度、准确性、推荐靠前度、引用来源和竞品声量。模型回答可能存在幻觉，因此报告保留原始问题、模型回答、识别出的来源和评分口径，结果适合作为 GEO 诊断与优化方向，不应被解读为唯一的市场事实依据。
